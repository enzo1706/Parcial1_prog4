Este proyecto es una aplicación web fullstack desarrollada como trabajo integrador, que permite gestionar productos, categorías e ingredientes de manera dinámica.

El sistema cuenta con un backend desarrollado en FastAPI con SQLModel, encargado de manejar la lógica de negocio, la persistencia de datos en una base PostgreSQL y la exposición de una API REST con operaciones CRUD completas.

Por otro lado, el frontend fue construido con React, TypeScript y Tailwind CSS, ofreciendo una interfaz moderna y responsiva que permite interactuar con la API en tiempo real.

La aplicación implementa funcionalidades como:

Creación, edición y eliminación de productos, categorías e ingredientes
Asociación entre productos, categorías e ingredientes (relaciones N:N)
Visualización de listados y detalle individual de productos mediante rutas dinámicas
Sincronización automática de datos utilizando React Query

Este proyecto aplica buenas prácticas de desarrollo como separación por capas, tipado fuerte, manejo de estado del servidor y organización modular del código.
